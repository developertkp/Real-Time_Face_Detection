# Real-Time_Face_Detection
Built a real-time face detection system in Python using OpenCV and YOLO that processes live video from a webcam. Handled frame capture, model inference and on-screen bounding-box display in a continuous video loop.


After Integrating database We can use this as a smart attendant system using face recognition For school colleges,

Required tools: Anaconda power shell, jupyter lab, yolo, python opencv.
